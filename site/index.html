CSS is awesome

Three drawings made only of HTML elements and CSS. I drew two of them in 2015 and the rocket in 2021, then redrew all three in 2026 with what CSS can do now. Drag the divider on a drawing to compare the two versions, and read both stylesheets below it.

Each drawing also has an AI power switch: it turns the right side into the version I made with Claude Code, as good as we could get it in as little CSS as possible.

No. 1 · March 2015

Hover the 2015 bicycle and it rides through the desert, with a flickering neon sign. It only worked with a mouse. The 2026 one also rides on keyboard focus and on tap.

Rocket

Drawn in 2021 inside a React app: Sass for the styles, and JavaScript to scatter 100 star elements, new ones on every render. The 2026 rocket needs no JavaScript, and it lifts off as you scroll past it.

About

The drawings are plain HTML and CSS with no build step. The 2015 and 2021 versions are the original files, shown in frames as they were, minus the music and a font I can’t share.

“Elements” counts the HTML elements in each drawing. Line counts skip comments and blank lines.

Source on GitHub. The React version from 2021 is kept at the tag legacy-2021.

Run it locally

  1. Clone the repository: git clone https://github.com/slimcandy/css3IsAwesome
  2. Serve the site folder with any static server: npx serve site
  3. To change the page styles, run npm install and npm run dev. The drawings themselves need nothing.
